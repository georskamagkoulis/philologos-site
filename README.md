# philologos-site

Html/Css/Js Project creating a custom website for my mother who is a teacher

Προσωπική ιστοσελίδα για φιλόλογο που κάνει ιδιαίτερα μαθήματα: στοιχεία επικοινωνίας, social, βιογραφικό, επιτυχίες και "Έμπνευση της ημέρας".

## Δομή

- `index.html` – το περιεχόμενο της σελίδας
- `style.css` – χρώματα, γραμματοσειρές, διάταξη
- `script.js` – μενού και "Έμπνευση της ημέρας"
- `images/` – φωτογραφίες

## Τι να αλλάξεις πρώτα

1. Στο `index.html`: όνομα, τηλέφωνο, email, βιογραφικό, αριθμοί επιτυχιών, κριτικές, links social (ό,τι γράφει "Όνομα Επώνυμο", "XX", "69X").
2. Βάλε φωτογραφία στο `images/` και αντικατάστησε το πλαίσιο φωτογραφίας στο hero.
3. Στο `script.js`: πρόσθεσε ρητά στη λίστα `QUOTES`, ή βάλε σύνδεσμο Google Sheet (CSV) στο `SHEET_CSV_URL`.
